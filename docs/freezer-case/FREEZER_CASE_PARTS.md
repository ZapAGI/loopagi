| **Chest Freezer 10 cu ft** (new, if needed) | Insignia, Midea, or GE brand | [Best Buy](https://www.bestbuy.com/site/searchpage.jsp?st=chest+freezer+10+cu+ft) / [Home Depot](https://www.homedepot.com/s/chest%20freezer%2010%20cu%20ft) | ~$250-350 new |

**Target specs for used freezer:**
- 10-14 cu ft capacity (internal ~38"W × 20"D × 24-26"H)
- Working compressor (plug in, should hum and get cold in 30 min)
- Manual defrost preferred (simpler)
- Clean interior, no rust, intact insulation
- Common brands: GE, Frigidaire, Insignia, Midea, Haier

## Quick-Buy Priority Order

Buy in this order to start building immediately:

| Priority | Item | Why First |
|---|---|---|
| 1 | **Chest Freezer** (used, 10+ cu ft) | Need physical dimensions to plan all zones |
| 2 | **XPS Foam Board + Spray Foam** | Build thermal barriers first |
| 3 | **CPU Water Block** (Heatkiller IV PRO TR) | Long shipping from Germany |
| 4 | **Barrow D5 Pump + Fittings + Tubing** | Core loop components |
| 5 | **Alphacool 360mm Radiator + Arctic Fans** | Zone 3 heat exchange |
| 6 | **ESP32 + Sensors + Displays** | Build monitoring during assembly |
| 7 | **Coolant supplies** (glycol, biocide, etc.) | Needed for fill/test |
| 8 | **PC Components** (CPU, board, RAM, PSU) | Install last after cooling is tested |
