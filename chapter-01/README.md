# Chapter 1: What We Talk About When We Talk About AGI

## Information Theory Foundations

Code examples for Chapter 1, covering Shannon entropy, Kolmogorov complexity,
and intelligence definition analysis.

### Files

- `shannon_entropy.py` - Shannon entropy calculator with visualizations
- `kolmogorov_complexity.py` - Kolmogorov complexity estimator using compression
- `intelligence_definitions.py` - Compare and classify 74 definitions of intelligence

### Running

```bash
uv run python chapter-01/shannon_entropy.py
uv run python chapter-01/kolmogorov_complexity.py
uv run python chapter-01/intelligence_definitions.py
```
