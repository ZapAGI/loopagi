# Chapter 2: The Monolith Delusion

## Emergence Simulation

Code examples for Chapter 2, demonstrating emergence: when the behavior
of the whole exceeds the sum of its parts.

### Files

- `emergence_simulation.py` - Simulate emergent behavior from simple agent rules
- `agent_coordination.py` - Multi-agent coordination without central control
- `phi_measure.py` - Formal emergence measure: Phi(S) > sum(Phi(s_i))

### Running

```bash
uv run python chapter-02/emergence_simulation.py
uv run python chapter-02/agent_coordination.py
uv run python chapter-02/phi_measure.py
```
